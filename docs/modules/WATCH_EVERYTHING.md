# WatchEverything — мониторинг интернета (P1)

Пользователь вводит разрешённый публичный URL, выбирает значение или элемент, условие и период проверки, выполняет тест, активирует монитор. Шаблоны: цена, наличие, новое объявление, вакансия, билеты, расписание, документы. Доступность зависит от разрешённых API и условий сайта. Не обещать универсальный мониторинг.

## Модель и процесс
Monitor: owner, URL, extraction_mode, selector/config, condition, schedule/timezone, active, last_success, last_value, status. Check: id, monitor_id, scheduled_at, fetched_at, outcome, normalized_value, change, error_code. Первый успешный результат — baseline; по умолчанию уведомить только при последующем изменении/переходе условия false→true. Режим повторных уведомлений настраивается отдельно. Ошибка не изменяет baseline. Повтор одного события дедуплицируется. Пауза, возобновление, удаление, тестовая проверка, история и отметка устаревших данных. Предлагаемый минимальный интервал 15 минут, с общим лимитом запросов на домен и backoff. Неуспешные проверки уведомляют после заданного порога, не на каждый сбой.

## Действия
watch.page.fetch: разрешённый URL → текст/metadata; watch.page.extract: selector/число/текст → typed value; watch.page.compare: current+baseline → change; условия core.condition; уведомления через integration/notification. Для динамических страниц изолированный браузер только при необходимости. Числа парсить с явной локалью и валютой, сравнение разных валют запрещено без конвертации. Нормализация whitespace и игнорирование выбранных динамических областей. Хранить минимум снимков с TTL.

## Защита
Только HTTP(S), ограниченные порты, запрет credentials в URL; проверять DNS и фактический IP, все redirects/subrequests, IPv4/IPv6/private/link-local/metadata, DNS rebinding; egress proxy/изоляция. Ограничить размер ответов, redirects, runtime и concurrency. Не обходить CAPTCHA, авторизацию, robots/условия источников, антибот-защиту. Секреты и полные URL с query не отправлять в логи/метрики. Не автоматически покупать/бронировать.

## Приёмка и аналитика
Локальный тестовый источник меняет цену и содержимое: одна ожидаемая нотификация, ошибки не создают false positives, пауза работает, повтор события не дублирует. Проверить timezone/DST, SSRF (включая redirects и DNS), rate limit и recovery. События watch.check_completed и watch.change_detected, метрики duration и notifications, без сырых страниц и URL. Сбор history и агрегатов с первого релиза модуля.

TASK-011 вводит ограниченный условный переход и состояния skipped. Модель fan-out/join и параллельные ветви появляются в TASK-015. Технические события соответствуют словарю ANALYTICS.
