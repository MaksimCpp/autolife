# AI Assistant

P1/P2. Не является исполнительным ядром. Создаёт черновики сценариев, объясняет ошибки и выполняет ограниченные действия по классификации, суммаризации, извлечению структурированных данных. Базовый FileFlow работает без AI.

## Конструктор
Пользователь описывает процесс. Backend предоставляет модели только доступные metadata действий/триггеров, схемы и безопасный контекст. Модель возвращает структурированный черновик либо уточнение/unsupported. Валидатор проверяет graph, config, bindings, scopes, квоты; UI показывает действия, необходимые подключения и побочные эффекты. Только явное подтверждение активирует сценарий. Неизвестные action IDs отклоняются, не создаются фиктивные действия.

## Обработка данных
ai.text.summarize, ai.text.classify, ai.data.extract: ограниченная схема результата, JSON validation, размер входа/выхода, timeout, budget. Сохранять provenance и неопределённость; отсутствующие поля null. Документы и сообщения — недоверенные данные, не инструкции. Модели не передаются секреты или прямой доступ к инструментам с побочными эффектами. AI не назначает права и не выполняет команды. Пользователь знает, какие данные передаются провайдеру; поддержать отключение AI для чувствительного содержимого.

## Стоимость и надёжность
Квоты на запросы/токены/бюджет, резервирование до вызова, сверка usage, модель и версия prompt в диагностике без содержимого. Rate limit, timeout, bounded retry, понятная ошибка провайдера. Выбор модели и актуальные API зафиксировать перед реализацией; provider adapter только когда нужен. Не обещать точность.

## Приёмка
Сценарий из поддерживаемых действий проходит validation; неподдерживаемый запрос не запускается; prompt injection из документа не вызывает внешних действий; malformed output отклоняется; quota и provider failure не ломают обычные сценарии. Извлечённые даты/обязательства требуют подтверждения. События ai.request_completed, ai.draft_generated и ai.draft_accepted, usage/cost — без текста prompt и документа.

TASK-014.08 объясняет безопасные machine codes и возможные действия пользователя на RU/EN. Модели передаётся allowlisted контекст без файлов, сырого текста ошибки, секретов, URL и полномочий. Если объяснение недоступно или невалидно, UI показывает локализованную справку по коду. Объяснение не изменяет и не запускает сценарий.
