# FileFlow — обработка файлов

## MVP
Пользователь загружает файлы, выбирает готовую операцию либо цепочку, настраивает её, запускает, наблюдает прогресс и скачивает результат. Одноразовая операция реализуется тем же engine. Не изменять исходник. Поддержка форматов определяется проверенными декодерами; MVP: JPEG, PNG, WebP, PDF; HEIC — этап TASK-015 после проверки декодера, совместимости и лицензий. Действия регистрируются с версией 1.

| Action | Вход → выход | Настройки |
|---|---|---|
| file.image.convert | image[] → image[] | jpeg/png/webp, quality 1–100, фон для прозрачности при JPEG |
| file.image.compress | image[] → image[] | quality 1–100 для lossy, lossless если формат поддерживает; не обещать уменьшение |
| file.image.resize | image[] → image[] | max_width/max_height, preserve_aspect_ratio, upscale=false по умолчанию |
| file.pdf.merge | pdf[] → pdf | явный порядок входов |
| file.pdf.split | pdf → pdf[] | диапазоны либо страницы по одному |
| file.pdf.extract | pdf → pdf | 1-based диапазоны с проверкой границ |
| file.pdf.create | image[] → pdf | A4/Letter/auto, порядок, fit, ориентация |

## Файлы и безопасность
100 МБ на файл, 250 МБ и 50 файлов на запуск, 20 шагов, 15 мин. Стартовые границы 40 Мпикс на изображение, 500 страниц, 250 МБ суммарного результата. Единицы, промежуточные лимиты и TTL заданы в REQUIREMENTS. Проверять magic bytes и декодирование, не расширение. Отклонять повреждённые/защищённые PDF в MVP. Нормализовать ориентацию; EXIF/GPS удалять по умолчанию для новых изображений, документировать. Не доверять именам, генерировать storage keys. Изолированная песочница без сети, credentials и host mounts; лимиты CPU/RAM/PIDs/disk/time. Исходники и результаты 7 дней, временные файлы до окончания; активные задачи удерживают ссылки. Удаление по TTL и по запросу, приватные краткосрочные ссылки. Атомарная публикация полного результата; частичный output не выдаётся за успех.

## Шаблоны MVP
Фото для отправки (resize+compress), фото в PDF, пакетная конвертация, объединение PDF, извлечение страниц, разделение PDF. Мастер показывает порядок, параметры, ориентировочные лимиты и выход. В MVP скачиваются отдельные файлы. Безопасный ZIP с пределом объёма появится в TASK-015.

## P1/P2
Crop/rotate, метаданные, OCR с выбором языка, извлечение текста/таблиц, CSV/XLSX, безопасные архивы (zip-slip, nested archive, decompression bomb), переименование/сортировка, точные дубликаты по хешу, FFmpeg аудио/видео, watermark, облачные входы/выходы. Не обещать точное распознавание произвольных таблиц; выводить confidence/предупреждения где доступно. Внешний AI только с разрешением.

## Аналитика и приёмка
События file.upload_completed, file.action_completed, download_link_issued по ANALYTICS; формат/число/байты/длительность/код ошибки без имени/содержимого. Проверить ориентацию, прозрачность, порядок, диапазоны, пропорции, недопустимый формат, oversized/decompression bomb, отмену и уборку, изоляцию пользователей, повторное выполнение, срок хранения. Каждый формат проверяется реальными fixtures. UI не показывает неподдерживаемый формат как доступный.

Загрузка — потоковый серверный multipart, один файл на запрос, UI ограничивает параллельность и формирует упорядоченный список ссылок. Профиль PDF в SECURITY обязателен на входе и выходе. OCR PDF получает ограниченно растеризованные страницы через изолированный профиль в TASK-013.
