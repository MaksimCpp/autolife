# FileFlow — обработка файлов

## MVP
Пользователь загружает файлы, выбирает готовую операцию либо цепочку, настраивает её, запускает, наблюдает прогресс и скачивает результат. Одноразовая операция реализуется тем же engine. Не изменять исходник. Базовые форматы MVP: JPEG, PNG, WebP, PDF. Дополнительные пары и условия выпуска приведены ниже. Действия регистрируются с версией 1.

| Action | Вход → выход | Настройки |
|---|---|---|
| file.image.convert | image[] → image[] | jpeg/png/webp, quality 1–100, фон для прозрачности при JPEG |
| file.image.compress | image[] → image[] | quality 1–100 для lossy, lossless если формат поддерживает; не обещать уменьшение |
| file.image.resize | image[] → image[] | max_width/max_height, preserve_aspect_ratio, upscale=false по умолчанию |
| file.pdf.merge | pdf[] → pdf | явный порядок входов |
| file.pdf.split | pdf → pdf[] | диапазоны либо страницы по одному |
| file.pdf.extract | pdf → pdf | 1-based диапазоны с проверкой границ |
| file.pdf.create | image[] → pdf | A4/Letter/auto, порядок, fit, ориентация |

## Файлы и безопасность
100 МБ на файл, 250 МБ и 50 файлов на запуск, 20 шагов, 15 мин. Стартовые границы 40 Мпикс на изображение, 500 страниц, 250 МБ суммарного результата. Единицы, промежуточные лимиты и TTL заданы в REQUIREMENTS. Проверять magic bytes и декодирование, не расширение. Отклонять повреждённые/защищённые PDF в MVP. Нормализовать ориентацию; EXIF/GPS удалять по умолчанию для новых изображений, документировать. Не доверять именам, генерировать storage keys. Изолированная песочница без сети, credentials и host mounts; лимиты CPU/RAM/PIDs/disk/time. Исходники и результаты 7 дней, временные файлы до окончания; активные задачи удерживают ссылки. Удаление по TTL и по запросу, приватные краткосрочные ссылки. Атомарная публикация полного результата; частичный output не выдаётся за успех.

## Шаблоны MVP
Фото для отправки (resize+compress), фото в PDF, пакетная конвертация, объединение PDF, извлечение страниц, разделение PDF. Мастер показывает порядок, параметры, ориентировочные лимиты и выход. В MVP скачиваются отдельные файлы. Безопасный ZIP с пределом объёма появится в TASK-015.

## P1/P2
Crop/rotate, метаданные, OCR с выбором языка, извлечение текста/таблиц, расширенная обработка CSV/XLSX, безопасные архивы (zip-slip, nested archive, decompression bomb), переименование/сортировка, точные дубликаты по хешу, FFmpeg аудио/видео, watermark, облачные входы/выходы. Не обещать точное распознавание произвольных таблиц; выводить confidence/предупреждения где доступно. Внешний AI только с разрешением.

## Аналитика и приёмка
События file.upload_completed, file.action_completed, download_link_issued по ANALYTICS; формат/число/байты/длительность/код ошибки без имени/содержимого. Проверить ориентацию, прозрачность, порядок, диапазоны, пропорции, недопустимый формат, oversized/decompression bomb, отмену и уборку, изоляцию пользователей, повторное выполнение, срок хранения. Каждый формат проверяется реальными fixtures. UI не показывает неподдерживаемый формат как доступный.

Загрузка — потоковый серверный multipart, один файл на запрос, UI ограничивает параллельность и формирует упорядоченный список ссылок. Профиль PDF в SECURITY обязателен на входе и выходе. OCR PDF получает ограниченно растеризованные страницы через изолированный профиль в TASK-013.

Приёмка загрузки TASK-003.02 зависит от launcher TASK-003.05 и изолированной инспекции TASK-003.06. Если инспекция недоступна или завершилась ошибкой, файл не переходит в ready.

## Дополнительные конвертации MVP

| Action v1 | Пары форматов | Параметры и результат |
|---|---|---|
| `file.document.to_pdf` | DOC/DOCX, XLS/XLSX, PPT/PPTX, ODT/ODS/ODP → PDF | По одному PDF на вход; печатная область таблиц, порядок слайдов, размер и ориентация источника по умолчанию |
| `file.text.to_pdf` | TXT → PDF | UTF-8 с необязательным BOM, размер/ориентация, поля и перенос строк |
| `file.html.to_pdf` | HTML → PDF | UTF-8, статическая печать, размер/ориентация и поля; внешние и локальные ссылки на ресурсы запрещены |
| `file.pdf.rasterize` | PDF → PNG/JPEG | Страницы или диапазоны, 72–300 DPI (150 по умолчанию), JPEG quality 1–100, фон и PNG alpha |
| `file.image.convert` | HEIC/HEIF или SVG → PNG/JPEG | Отдельные ограничения по парам в реестре; выход один на вход, для HEIF — основной still image, последовательности вне MVP |
| `file.table.convert` | XLSX ↔ CSV | Выбор листа для XLSX → CSV, первый по порядку по умолчанию; UTF-8, запятая по умолчанию, фиксированный список разделителей; один лист для CSV → XLSX |

HEIC/HEIF входит в объём MVP как decode-only. До включения требуется положительная проверка профилей контейнера и кодека на поставляемой сборке для всех целевых архитектур, ориентации, цвета, памяти и условий использования. При отрицательном результате capability скрыта и отвергается сервером, TASK-007A.06 остаётся blocked до решения владельца о способе выполнения или явном изменении объёма MVP.

Для новых действий используются упорядоченные списки типизированных file refs. В пакетах выход упорядочен сначала по входу, затем по возрастанию номера страницы; диапазоны нормализуются без дубликатов. Изоляция действует на каждый запуск обработчика. Один отказ прекращает шаг, удаляет staging этого шага и указывает позицию входа. Результаты успешных предшествующих шагов сохраняются по ADR-002. Быстрый запуск использует тот же engine с одношаговым снимком. PDF и активные исходники скачиваются как attachment. Предпросмотр допускается для авторизованной ограниченной растровой производной.

### Качество и совместимость

- Офисный экспорт сохраняет текст, базовое форматирование, таблицы, изображения и порядок страниц/слайдов в пределах фильтров. По умолчанию сохраняются размеры и ориентация страниц, печатные области и разрывы. Метрики шрифтов, формулы, сложная вёрстка и анимация могут отличаться. Показывать известную подстановку шрифта или потерю поддерживаемого свойства, когда детектор даёт достоверный результат.
- Поставлять закреплённый набор открытых шрифтов (Noto, Liberation по подтверждённым лицензиям), учитывать разрешение на встраивание и лицензию каждой семьи. Проверять кириллицу, латиницу, CJK и RTL на fixtures с подключёнными наборами; границы покрытия публикуются в каталоге. Пользовательские встроенные шрифты в MVP не устанавливаются и не загружаются.
- PNG сохраняет поддерживаемую прозрачность, JPEG композитится на белый или заданный фон. Нормализовать ориентацию и цвет в sRGB с учётом поддерживаемых встроенных ICC; не обещать сохранение HDR/CMYK. Некорректный профиль обрабатывать явной ошибкой или документированным предупреждением. Удалять EXIF/GPS, комментарии, миниатюры и произвольные свойства у производных; выходной sRGB-профиль допустим. PDF проходит проверку статического профиля и очистку приватных метаданных.
- CSV сохраняет данные выбранного листа как плоскую таблицу. Формулы не вычисляются: допустимы сохранённые значения, при их отсутствии возвращается предупреждение и пустая ячейка. Стили, формулы, графики, объединения и остальные листы теряются. CSV-экспорт нейтрализует опасные формульные префиксы и сообщает об экранировании; CSV-импорт пишет значения как текст, сохраняя ведущие нули и не выполняя формулы. Проверять кавычки, многострочные поля, CRLF/LF, кириллицу, лимиты строк/столбцов/ячеек.
- Обратная конвертация P2 восстанавливает редактируемый текст или табличную сетку эвристически. PDF → DOCX сохраняет порядок чтения и доступные изображения по возможности; колонки, шрифты и разметка могут измениться. PDF → XLSX извлекает обнаруженные таблицы; стили, формулы и точная сетка не гарантируются, неоднозначные ячейки отмечаются. Для сканов требуется OCR; при отсутствии надёжных данных возвращать предупреждение или ошибку, не генерировать значения.

### Ресурсные пределы

Предварительные стартовые максимумы на вызов профиля. Общие лимиты REQUIREMENTS применяются одновременно. Байты входа и выхода в таблице — суммарные на вызов, любой отдельный файл ограничен 100 МБ. Параллелизм — число активных процессов обработки по профилю на worker host, поверх общего и пользовательского предела. Оператор настраивает каждое значение до релиза по результатам замеров; параметры пользователя могут только сужать бюджеты.

| Профиль | Вход/выход, МБ | Страницы / пиксели / длительность | Время | CPU / RAM | Временный диск | Параллелизм |
|---|---:|---|---:|---|---:|---:|
| Изображения, включая SVG/HEIF | 100/100 | 40 Мпикс на растр, 120 Мпикс на вызов | 30 с | 1 vCPU / 512 МиБ | 384 МБ | 2 |
| PDF | 250/250 | 500 страниц; растр 40 Мпикс/страница и 200 Мпикс/вызов | 90 с | 1 vCPU / 768 МиБ | 768 МБ | 2 |
| Документы Office/TXT | 100/100 | 500 выходных страниц | 120 с | 2 vCPU / 1024 МиБ | 512 МБ | 1 |
| HTML | 25/100 | 500 выходных страниц, 40 Мпикс на встроенное растровое изображение и 120 Мпикс на вызов | 90 с | 2 vCPU / 1024 МиБ | 512 МБ | 1 |
| Таблицы | 100/100 | 100 тыс. строк, 256 столбцов и 1 млн ячеек | 60 с | 1 vCPU / 512 МиБ | 384 МБ | 1 |
| Аудио P2 | 100/100 | 30 мин | 180 с | 1 vCPU / 512 МиБ | 384 МБ | 1 |
| Видео P2 | 100/100 | 10 мин, 1920×1080 и 60 fps максимум | 600 с | 2 vCPU / 1536 МиБ | 768 МБ | 1 |

Для контейнерных документов дополнительно конфигурировать суммарный и поэлементный размер распакованных данных, число элементов, глубину и коэффициент расширения. Для многостраничного вывода считать артефакты, суммарные страницы, пиксели и байты до публикации. Размер, длительность и страницы из заголовков перепроверять в профиле; остановка и освобождение ресурсов следуют ADR-001/002.

### Распределение после MVP

- P1, TASK-013: OCR изображений и статических PDF, RU/EN с выбором языка; повторно использовать изолированную растеризацию. Результат с привязкой к страницам и доступными признаками неопределённости.
- P2, TASK-015: PDF → DOCX/XLSX; электронные книги без DRM, стартово EPUB ↔ FB2; конвертация аудио MP3/WAV/FLAC/AAC/OGG и видео MP4/WebM/MOV/MKV по явной матрице контейнеров, кодеков и направлений; профили сжатия и извлечение аудио из видео. Расширение сохраняет операции из прежнего плана P1/P2 и отдельно утверждает дополнительные пары.
