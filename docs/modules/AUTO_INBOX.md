# AutoInbox — входящая информация (P1)

## Сценарии
Подключить Gmail (если доступ и верификация приложения разрешены), позже Outlook/IMAP; принимать добровольно пересланные сообщения и файлы через Telegram. Настроить источник, папку/метку, фильтры, действие и тестовый запуск. Шаблоны: сохранить вложения, извлечь задачи, чеки в таблицу, трек-номера, сводка важных писем. Не обещать доступ к личным чатам через обычного бота.

## Модель и синхронизация
SourceConnection, SyncCursor, MessageRef (provider_id, owner, timestamps), AttachmentRef, ProcessingRecord (workflow_version, source/event id, status). Получать только необходимые данные, минимум сохранять. Initial sync ограничен выбранным периодом; не обрабатывать архив по умолчанию. Cursor checkpoint атомарно после durable записи события; при сбое повторная доставка дедуплицируется. Отзыв доступа останавливает новые получения; история и данные удаляются согласно настройкам и срокам.

## Действия
inbox.email.filter (sender/domain/subject/attachment), inbox.attachment.extract, inbox.email.extract (структура), inbox.message.tasks, inbox.receipt.extract, inbox.tracking.extract, inbox.digest.create. Категоризация/сводки через AI при разрешении; трекинг только через разрешённые API перевозчиков. Вложения передавать в FileFlow как приватные ссылки. Письма и HTML — недоверенные данные; не загружать remote tracking pixels, санитизировать превью, не выполнять инструкции из писем. Отправка, удаление, архивирование и внешние записи — по явно утверждённой политике/разрешению; опасные операции требуют подтверждения.

## Приёмка
Тестовый mailbox: одно письмо обрабатывается один раз, фильтр работает, вложение проходит файловую проверку, повторный sync/cursor loss не создаёт дубли. Ошибки доступа, rate limits, отзыв токена и восстановление проверены. Вредоносное письмо не меняет сценарий или разрешения. Не отправлять тело письма, тему, адреса, имена вложений или содержимое в аналитику; допустимы counts, outcomes, latency. Сводка явно обозначает неполные данные.

P1 в TASK-012 ограничивается известными текстовыми источниками и детерминированными правилами для задач, чеков и сводок. Нераспознанные поля остаются пустыми. OCR появляется в TASK-013, AI-обработка по согласию в TASK-014. Внешняя запись P1 доступна только по явно настроенной политике разрешённых эффектов после проверки TASK-012.05. Операции, требующие интерактивного подтверждения, активируются после общего механизма TASK-013.05.
