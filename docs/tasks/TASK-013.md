# TASK-013 — LifePilot

Статус: planned. Зависимости: 012.

## Цель

Реализовать личные обязательства, календарь, напоминания и подтверждение данных.

## Источники требований

AGENTS.md; docs/ROADMAP.md; docs/REQUIREMENTS.md; docs/TESTING.md. Дополнительно (пути относительно docs/): modules/LIFE_PILOT.md, modules/FILE_FLOW.md, modules/WORKFLOW_ENGINE.md, UI_UX.md.

## Подзадачи и критерии приёмки

### TASK-013.01 — Обязательства

- [ ] Статус: planned.
- Зависимости: зависимости этапа, указанные выше.
- Реализация: Написать migrations obligations/occurrences/reminders/candidates, CRUD/list filters, amount+currency, date vs datetime, owner access.
- Критерии приёмки: Разовые и повторяющиеся записи сохраняются; чужие данные закрыты; деньги без float rounding.

### TASK-013.02 — Повторяемость

- [ ] Статус: planned.
- Зависимости: TASK-013.01.
- Реализация: Реализовать recurrence rules, timezone/DST, end-of-month policy, generation occurrences, completion/skip/reschedule.
- Критерии приёмки: Завершение одного occurrence не закрывает серию; изменение будущих дат атомарно отменяет устаревшие reminders.

### TASK-013.03 — Напоминания

- [ ] Статус: planned.
- Зависимости: TASK-013.02.
- Реализация: Написать durable scheduler на существующей очереди, offsets/channels, dedup occurrence+reminder+channel, cancel и bounded retries.
- Критерии приёмки: Повтор доставки не создаёт новый logical reminder; перенос/завершение отменяет ненужное; timezone тесты проходят.

### TASK-013.04 — OCR и черновики

- [ ] Статус: planned.
- Зависимости: TASK-013.03, TASK-007A.04.
- Реализация: Добавить изолированное file.document.ocr через утверждённый Tesseract, извлечение проверяемых дат/сумм и evidence refs, кандидат с uncertainty/null; AI расширение в 014. Переиспользовать растеризацию PDF из TASK-007A.04 в изолированном профиле с суммарными лимитами, выбрать языки OCR.
- Критерии приёмки: Чек без гарантии не создаёт выдуманный срок; OCR fixtures и sandbox limits проверены; исходник может истечь без поломки записи. Многостраничные fixtures, отмена, пределы страниц/пикселей и истечение исходника проверены.

### TASK-013.05 — Durable approval

- [ ] Статус: planned.
- Зависимости: TASK-013.04.
- Реализация: Реализовать запрос подтверждения, хранение решения и resume после ответа без удержания воркера; уточнить состояния ожидания и контракт в docs до реализации. Добавить expiry, deny/revoke, owner/version/step scope, повторную проверку прав и квоты при resume; связать с TASK-012.05.
- Критерии приёмки: Без подтверждения обязательство не активируется; restart сохраняет запрос; повтор подтверждения идемпотентен. Ожидание не удерживает worker и имеет отдельный срок; старое решение не применяется к изменённому эффекту.
