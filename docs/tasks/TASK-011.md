# TASK-011 — WatchEverything

Статус: planned. Зависимости: 010.

## Цель

Добавить мониторинг сайтов, расписания и условные автоматизации.

## Источники требований

AGENTS.md; docs/ROADMAP.md; docs/REQUIREMENTS.md; docs/TESTING.md. Дополнительно (пути относительно docs/): modules/WATCH_EVERYTHING.md, modules/WORKFLOW_ENGINE.md, SECURITY.md, UI_UX.md.

## Подзадачи и критерии приёмки

### TASK-011.01 — Планировщик

- [ ] Статус: planned.
- Зависимости: зависимости этапа, указанные выше.
- Реализация: Написать schedule model/migrations, timezone/DST, due job scanner, dedup occurrence, pause/missed/overlap policy; зарегистрировать core.schedule/datetime.
- Критерии приёмки: Fake-clock тесты DST и restart; один occurrence создаёт один запуск; inactive не запускается.

### TASK-011.02 — Условия

- [ ] Статус: planned.
- Зависимости: TASK-011.01.
- Реализация: Расширить валидатор и engine на ограниченный последовательный условный переход с альтернативой, без fan-out/join, typed comparisons AND/OR/NOT, skipped states; добавить UI блок условия.
- Критерии приёмки: False branch не исполняется; несовместимые типы и циклы отклонены; линейные MVP workflows не ломаются.

### TASK-011.03 — Модель монитора

- [ ] Статус: planned.
- Зависимости: TASK-011.02.
- Реализация: Написать monitors/checks/baselines migrations, CRUD/pause/resume/test API, quota и owner checks.
- Критерии приёмки: Чужие мониторы недоступны; пауза прекращает новые проверки; история сохраняется по TTL.

### TASK-011.04 — Защищённый HTTP fetch

- [ ] Статус: planned.
- Зависимости: TASK-011.03.
- Реализация: Реализовать HTTP(S) allowlist портов, DNS/IP validation и pinning, redirects, egress policy, timeout/body/rate limits; не обходить ограничения сайта.
- Критерии приёмки: SSRF тесты IPv4/IPv6, private/metadata, redirect и rebinding не проходят к запрещённым адресам; локальный fixture разрешён только тестовым профилем.

### TASK-011.05 — Извлечение значений

- [ ] Статус: planned.
- Зависимости: TASK-011.04.
- Реализация: Написать text/selector/numeric extract, нормализацию whitespace, локаль/валюту, availability и игнорируемые области; JS browser только в утверждённом изоляторе.
- Критерии приёмки: Fixtures дают ожидаемые значения; разные валюты не сравниваются; неуспешный fetch не даёт ложное изменение.

### TASK-011.06 — Baseline и уведомления

- [ ] Статус: planned.
- Зависимости: TASK-011.05.
- Реализация: Реализовать атомарную запись baseline/check, false→true и change events, dedup notification, порог ошибок/backoff и watch.page_changed trigger.
- Критерии приёмки: Первый check baseline; одно изменение — одно событие; ошибки не меняют baseline; повтор доставки безопасен.

### TASK-011.07 — UI и шаблоны

- [ ] Статус: planned.
- Зависимости: TASK-011.06.
- Реализация: Написать страницу Watch, URL/selector/condition/schedule wizard, test preview, history, status, templates цены/наличия/объявлений/вакансий/билетов/расписаний для разрешённых источников.
- Критерии приёмки: Пользователь создаёт и останавливает монитор; неподдерживаемый источник явно объяснён; RU/EN и обе темы.

### TASK-011.08 — Метрики и приёмка мониторинга

- [ ] Статус: planned.
- Зависимости: TASK-011.07.
- Реализация: Добавить watch actions registry, count/check duration/outcome/change metrics, тесты и лимиты; выполнить приёмку функций мониторинга; финальная проверка этапа в 011.09.
- Критерии приёмки: E2E на контролируемом источнике; SSRF/DST/dedup тесты пройдены; без реального деплоя.

### TASK-011.09 — Триггер file_uploaded

- [ ] Статус: planned.
- Зависимости: TASK-011.08.
- Реализация: Подписать opt-in trigger на committed file.upload_completed пользовательских загрузок, соединить owner, workflow_version и source file. Публикацию outputs и импорты других модулей исключить из источника P1.
- Критерии приёмки: Повтор доставки создаёт один запуск на workflow/version/file, expired или чужой вход блокируется, собственные результаты не зацикливают триггер. Повторить применимые release-проверки.

- Прочитать AGENTS.md и перечисленные документы, сверить зависимости и существующий код. При конфликте требований остановиться и зафиксировать вопрос, не менять согласованный контракт самостоятельно.
