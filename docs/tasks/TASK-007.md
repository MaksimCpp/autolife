# TASK-007 — PDF-действия

Статус: planned. Зависимости: 005,006.

## Цель

Реализовать операции с PDF и цепочки изображение → PDF.

## Источники требований

AGENTS.md; docs/ROADMAP.md; docs/REQUIREMENTS.md; docs/TESTING.md. Дополнительно (пути относительно docs/): modules/FILE_FLOW.md, SECURITY.md, modules/WORKFLOW_ENGINE.md.

## Подзадачи и критерии приёмки

### TASK-007.01 — PDF adapter

- [ ] Статус: planned.
- Зависимости: зависимости этапа, указанные выше.
- Реализация: Подключить проверенные qpdf/img2pdf или утверждённые аналоги в sandbox; инспекция page count, encryption, повреждений, безопасные аргументы. Применить статический профиль SECURITY к входам и выходам, проверить лицензии выбранного образа и преобразование WebP.
- Критерии приёмки: Невалидные/зашифрованные PDF отклонены; page limit соблюдён; нет shell interpolation. Интерактивный PDF и вложения запрещены. Обычные операции и выходы подтверждены fixtures.

### TASK-007.02 — Объединение

- [ ] Статус: planned.
- Зависимости: TASK-007.01.
- Реализация: Реализовать file.pdf.merge v1 с упорядоченным списком входов, новым output и проверкой лимита страниц.
- Критерии приёмки: Тестовые PDF объединяются в заданном порядке с правильным количеством страниц.

### TASK-007.03 — Разделение и извлечение

- [ ] Статус: planned.
- Зависимости: TASK-007.02.
- Реализация: Реализовать file.pdf.split и file.pdf.extract v1, 1-based диапазоны, проверку границ, безопасные имена результатов.
- Критерии приёмки: Fixtures проверяют диапазоны, дубликаты согласно утверждённой политике, выход за границы, порядок и количество выходов.

### TASK-007.04 — Создание PDF

- [ ] Статус: planned.
- Зависимости: TASK-007.03.
- Реализация: Реализовать file.pdf.create v1 из image[] с A4/Letter/auto, fit, ориентацией и порядком.
- Критерии приёмки: Количество и порядок страниц совпадают с изображениями; пропорции и ориентация проверены; лимиты output соблюдены.

### TASK-007.05 — Результаты и интеграция

- [ ] Статус: planned.
- Зависимости: TASK-007.04.
- Реализация: Зарегистрировать schemas, подключить worker и артефакты; реализовать безопасное скачивание отдельных результатов. ZIP перенесён в TASK-015.15.

## Правила выполнения и завершения

- Прочитать AGENTS.md и перечисленные документы, сверить зависимости и существующий код. При конфликте требований остановиться и зафиксировать вопрос, не менять согласованный контракт самостоятельно.
- Выполнять одну подзадачу за раз в порядке списка; все предыдущие подзадачи этого файла являются зависимостями, если явно не согласован иной порядок. Не переходить к следующей без указания владельца. Отмечать чекбокс только после выполнения критериев; при блокере указать partial/blocked.
- Для задач реализации писать настоящий код, миграции, конфигурации и тесты; подключать компоненты к приложению. Не заменять обязательную функциональность заглушками. Тестовые doubles допустимы только в тестах или явно обозначенном dev режиме.
- Проверять безопасность, owner scope, ошибки и ограничения там, где применимо. Не использовать реальные production secrets, не выполнять push/deploy без разрешения. Не добавлять функциональность других этапов заранее.
- Запускать применимые проверки из TESTING.md: unit/integration, race для конкурентного Go-кода, frontend lint/typecheck/build и E2E, migration/security checks. Записать фактическую команду, результат и непроверенные условия. Не утверждать, что тест прошёл, если он не запускался.
- Обновить затронутую документацию, список изменённых файлов, ADR при необходимости и статус ROADMAP. Весь этап завершён только после прохождения всех подзадач и итоговых критериев. Остановиться после отчёта.
