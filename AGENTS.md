# AGENTS.md — AutoLife

Работай как инженер проекта. Сначала изучи README, docs/PRODUCT.md, REQUIREMENTS.md, ARCHITECTURE.md, TECH_STACK.md, SECURITY.md, соответствующий модуль и конкретную задачу. ROADMAP и явные зависимости подзадач определяют порядок. Согласованные архитектурные решения хранятся в docs/adr. Документация — источник требований; при конфликте зафиксируй и запроси согласование, не изменяй смысл молча. Проектируй для полной платформы, реализуй только текущий этап.

## Правила
- Не добавляй будущие модули, зависимости, микросервисы и абстракции без необходимости. Не меняй стек без согласования.
- Домен отделён от транспорта/инфраструктуры. Новый action не требует изменения основного алгоритма engine. Не дублируй бизнес-логику.
- Обрабатывай ошибки, context cancellation, resource limits, concurrency. Не доверяй клиенту, файлам, внешним данным или AI. Проверяй owner, минимальные права, no secrets in logs/Git. Не используй shell interpolation, произвольный код и опасный доступ к Docker socket.
- Пиши unit/integration/E2E тесты по задаче; не отключай проверки. Не оставляй заглушки вместо обязательной функциональности.
- Обновляй API/DB/модульную документацию при изменении контрактов, фиксируй ADR. Не публикуй production, не пушь и не выполняй необратимые команды без явного разрешения.

## Процесс
1. Прочитай задачу, зависимости и существующий код; обозначь план и риски.
2. Реализуй только заданный scope.
3. Запусти применимые тесты, линтеры, build, security checks. Укажи точные результаты и непроверенное.
4. Проверь критерии приёмки, обнови ROADMAP только если выполнены; иначе partial/blocked.
5. Перечисли файлы, решения, ограничения и дальнейшие риски. Остановись, не переходи к следующей задаче автоматически.

## Гранулярность задач
Каждый TASK-XXX.md содержит подзадачи TASK-XXX.YY. Если пользователь указал подзадачу, реализуй только её и остановись. Если указан целый этап, начни с первой незавершённой подзадачи; не переходи дальше без указания владельца. TASK-000 — только проектирование. Статус этапа обновляется после выполнения всех подзадач.
